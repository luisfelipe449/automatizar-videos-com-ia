# Canal de cortes GTA 6 (Five Star Clips) — Implementation Plan

> **For agentic workers:** steps use checkbox (`- [ ]`) syntax for tracking. Funções puras em TDD (teste primeiro); render com teste de snapshot do comando + um teste `slow` que roda o FFmpeg de verdade.

**Goal:** Produzir automaticamente, todo dia às 08h BRT, as edições "Top Clips of the Day" e "Funny Moments" (Short 9:16 + médio 16:9, em pt-BR e en) a partir de clips da Twitch de GTA 6. As edições ficam no dashboard para aprovação e upload manual.

**Architecture:** Novo pacote `app/clips/` independente do pipeline de prompt. Fonte (`ClipSource`) → `Clip` no banco → download (yt-dlp) → classificação (Gemini vídeo, fallback Groq) → seleção pura → render em dois passes (base neutra + camada de idioma) → `Edition` aguardando aprovação. O sistema operacional agenda o ponto de entrada `python -m app.clips`.

**Tech Stack:** Python 3.13, SQLAlchemy 2.x/SQLite, FFmpeg 8, yt-dlp, Twitch Helix, google-genai (Gemini Flash + TTS), Groq, FastAPI/Jinja2, pytest.

**Spec:** `docs/superpowers/specs/2026-11-17-gta6-clips-design.md`

**Calendário:** 17/11 → Tasks 0–8 · 18/11 → Tasks 9–15 · 19/11 manhã → Task 16 (primeiro lote real) · até 26/11 → Fase 2.

## File Structure

| Arquivo | Responsabilidade |
|---|---|
| `app/clips/__main__.py` | CLI: `python -m app.clips daily [--date]`, `weekly`, `harvest`, `render <edition>` |
| `app/clips/models.py` | Pydantic: `CandidateClip`, `ClipVerdict`, `ChannelProfile`, `EditionPlan` |
| `app/clips/profiles.py` | Carrega `assets/input/channels/<perfil>.json` → `ChannelProfile` |
| `app/clips/formats.py` | `FormatSpec` de cada formato (aspecto, duração, nº de clips, janela, ranking) |
| `app/clips/sources/base.py` | Protocolo `ClipSource.fetch(since, until) -> list[CandidateClip]` |
| `app/clips/sources/twitch.py` | Token de app, `game_id` do GTA VI, `Get Clips` paginado |
| `app/clips/download.py` | yt-dlp → `assets/clips/raw/<source>_<id>.mp4` + proxy de 480p |
| `app/clips/classify.py` | Gemini (vídeo) → `ClipVerdict`; fallback Groq (título) |
| `app/clips/select.py` | Ranking e montagem das edições: funções puras |
| `app/clips/render.py` | Montagem dos comandos FFmpeg (puros) + execução: base, idioma, thumbnail |
| `app/clips/outro.py` | Outro provisório, CTA em TTS (cache eterno), adaptação 16:9/9:16 |
| `app/clips/metadata.py` | Título `#N`, descrição, capítulos |
| `app/clips/pipeline.py` | Orquestra os estágios idempotentes de uma edição |
| `app/db/models.py` | `Clip`, `Edition`, `EditionClip`; `Account.channel_profile` |
| `scripts/migrate_clips.py` | Cria as tabelas novas + `ALTER TABLE accounts ADD channel_profile` |
| `app/web/routes/editions.py` + `templates/editions*.html` | Lote do dia, players, aprovar/rejeitar, baixar, copiar |
| `assets/input/channels/five-star-clips{,-br}.json` | Perfis dos canais |
| `assets/icons/{twitch,kick,youtube}.png` | Ícones do crédito |
| `assets/input/outro_16x9.mp4` | Outro da Kling (opcional; sem ele, usa o provisório) |
| `scripts/schedule_clips.md` | Como agendar (cron no WSL / Agendador de Tarefas) |

Artefatos por edição: `assets/clips/editions/<edition_key>/` (`plan.json`, `base_16x9.mp4`, `base_9x16.mp4`, `{lang}/medio.mp4`, `{lang}/short.mp4`, `{lang}/thumb.png`, `status.json`). `edition_key` = `<data>_<formato>`, ex.: `2026-11-19_top_daily`.

## Fase 2 (até 26/11) — esboço, detalhar ao começar

- **Semanais**: `run_weekly(kind)` na quinta (Top 10 Plays: views na semana, `category ∈ {play, wtf}` desempata) e na sexta (Funny da semana). Só longo 16:9 + thumbnail.
- **Link de live (YouTube/Kick)**: formulário no dashboard → `LiveLinkSource`:
  1. áudio via yt-dlp;
  2. `ebur128` para picos;
  3. Groq Whisper em pedaços < 25 MB (respeitando 28.800 s/dia no free tier);
  4. Groq/Llama em janelas de 12 min devolve trechos candidatos;
  5. `yt-dlp --download-sections` só nos trechos;
  6. vira `Clip` com `source=youtube|kick` e passa pelo mesmo classificador.
- **Depois**: upload automático (`Job` de upload por edição × canal, assim que a auditoria sair), Kick automático, layout com facecam, médio de WTF.
